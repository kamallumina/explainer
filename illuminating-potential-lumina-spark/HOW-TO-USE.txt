eLearning Course Glossary - Quick Setup Guide
=====================================================

STEP 1: Upload glossary-data.json to Your Platform
---------------------------------------------------
Upload the glossary-data.json file to your eLearning course or website

STEP 2: Add Script to Your Course
----------------------------------
You have TWO options:

OPTION 1 - Use CDN (RECOMMENDED - Easiest!)
--------------------------------------------
Just add this code (no JS file upload needed):

<script src="https://ai-4-id.b-cdn.net/rise-glossary.js" 
        data-auto-init="true" 
        data-data-url="glossary-data.json">
</script>

✅ Benefits: No file management, always updated, faster

OPTION 2 - Use Local File
--------------------------
1. Click "Download JS" button in the editor
2. Upload rise-glossary.js with your glossary-data.json
3. Add this code:

<script src="rise-glossary.js" 
        data-auto-init="true" 
        data-data-url="glossary-data.json">
</script>

STEP 3: Publish and Test
-------------------------
✓ Preview or publish your course
✓ Terms will be automatically highlighted
✓ Hover/click on highlighted terms to see definitions

Platform-Specific Help:
-----------------------
Articulate Rise 360: Add files, then use Code Block lesson
Articulate Storyline: Include files in published output
Moodle/Canvas: Upload to course files, add script to HTML page
WordPress: Upload to Media Library, add to Custom HTML block
